# 大屏切换天地图二维实现

## 变更

- 农业微应用与大屏子包的 package.json、npm/pnpm 锁文件和 catalog 移除 Maptalks；`pnpm why maptalks -r` 无依赖结果。
- FieldGeoStage、RemoteAnalysisStage 改用 `packages/bigscreen/src/utils/tianditu.js` 的天地图 API 4.0 二维适配。保持原页面的数据来源、颜色分层、地块详情、告警/无人机标记、遥感服务及日期联动。
- 沿用管理端 HTTPS 天地图 WMTS 影像与注记配置；删除 pitch、bearing 和 WebGL 配置。
- Key 不再写在两个组件中；使用 VITE_TIANDITU_KEY。大屏本地环境沿用迁移前 Key，部署环境可以覆盖，也可以继承农业应用配置。
- SDK 加载失败显示明确提示；销毁时解除自己的 ResizeObserver、影像事件和覆盖物。适配实际 SDK 没有 Map.remove 的情况，避免路由卸载异常。
- 当前 SDK 没有 ImageOverlay 构造器，遥感覆盖物改用天地图 getPanes().overlayPane 与 lngLatToLayerPoint 定位图片，随移动、缩放和尺寸变化更新，移除时解绑事件。影像请求序号避免异步旧结果覆盖新选择。
- 源 ym-vue、源 sf-screen 未改动；之前删除的农业 home-overview 菜单没有恢复。

## 验证

- 7 项地图适配测试及 4 项页面覆盖测试通过（共 11 项）。地图测试检查二维底图、缩放边界、地块样式/范围、HTML 内容委托净化、影像投影和清理、无原生析构方法的卸载；不是第三方 SDK 的完整测试。
- 农业 `pnpm typecheck` 通过。
- `pnpm build` 通过，包含独立大屏构建到 public/bigscreen 及农业主应用生产构建。
- src、大屏 src、public/bigscreen、最终 dist 均未发现 Maptalks 字符串；旧未使用的大屏 dist 已归档移出工程。
- 浏览器在临时大屏开发服务验证二维影像底图、地块边界和告警标记；地块点击弹窗展示种植区、作物、面积、长势等原有信息。
- 遥感覆盖图实际加载，放大后覆盖尺寸由约 302×268 变为 604×536；切换叶绿素时统计标题联动，切换历史影像日期显示 2025-09-22。
- IoT 地图缩放、深浅主题切换及页面卸载验证完成。最终修复后本轮后续交互没有新增地图错误。

## 边界与回退

- 测试中仍使用大屏原有模拟数据，未将示例地块、设备与告警声称为生产数据或真实设备联调。
- 浏览器截图验证使用当前窗口（画面约 1280×720，页面内部仍按大屏设计比例缩放）；未穷尽全部分辨率、异常网络和 SDK 版本。
- 天地图第三方脚本曾记录 military.js 的 extend 初始化异常；最终二维地图正常呈现，未修改第三方脚本。
- 原文件及依赖清单备份：`/tmp/tianditu-migration-oaaE1v/before.tar.gz`；旧大屏构建物在同目录 previous-bigscreen-dist。临时目录需长期保存时应另行归档。
