# 平台超级管理员跨租户访问验证（2026-09-04）

## 范围与实现

- SaaS 平台超级管理员以可信全局账号 ID 判断，不通过角色名称或前端权限声明提升身份。
- 可列出、进入所有有效租户；停用、删除、过期租户仍拒绝进入。
- 首次进入目标租户建立该全局账号自己的本地成员；不借用其他账号、不复制密码、不新增角色授权。锁和数据库唯一约束防止重复成员。
- 切换后的超级管理员会话授予全部菜单/按钮权限，应用不受租户套餐限制；普通账号继续受成员、套餐及角色权限交集限制。
- 仅放开超级管理员的数据权限范围，业务 SQL 的当前租户过滤保留。
- 修复虚拟线程没有 Sa-Token 上下文时构建登录用户报错：无上下文不得继承管理员身份，完整登录对象构建后再按可信全局身份赋权。
- SaaS 前端租户列表允许尚未创建本地成员的 userId 为空，切换使用 tenantId。
