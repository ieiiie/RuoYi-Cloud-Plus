# 库存页面与溯源码复制修复记录

日期：2026-09-04。范围为用户提交的 10 处农业微应用反馈。

## 根因和修改

- 库存公共表头覆盖使用半透明背景，固定操作列表头会透出后方滚动列。改为不透明的 Ant 主题表头背景。
- Ant 新版加载容器为 `.ant-spin`，旧 `.ant-spin-nested-loading` 选择器未命中，满高表格和分页布局失效。按实际 DOM 修复。
- 单据列表固定横向宽度不足以容纳业务列，改为内容宽度滚动；不删除业务列。窄屏仍须横向滚动查看全部列。
- 库存抽屉原宽度类名未影响新版 Drawer 的实际尺寸，始终使用默认 520px。流水、单据创建、单据详情、历史修正使用显式响应式 960px 尺寸，资产详情使用 760px。
- 农业服务遗漏了 `i18n/stask/messages*.properties`。从只读源项目补齐默认、中文和维文资源；StaskMessageResolver 独立加载领域资源并以平台 MessageSource 为父级，不覆盖平台消息配置。
- 前端保留服务端已翻译标签，对旧运行包返回的 52 个库存资源键按源中文资源进行兼容解析；未知资源键回退现有枚举。不同单据的 COMPLETED 分别展示已入库、已出库、已完成。
- 列表创建/提交时间和物料更新时间使用项目现有 formatDateTime。
- 溯源码及溯源批次复制改用无界 shadowRoot 所属可见文档的剪贴板，避免隐藏 iframe 焦点问题；增加选区复制回退、失败反馈、焦点恢复及临时节点清理。
