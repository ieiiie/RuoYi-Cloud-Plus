# 组合应用完整布局修复

## 实现

SaaS 前端 `bell-plus` 的组合应用复用现有应用级 `BasicLayout`、`VbenAdminLayout`、标准菜单、顶部工具栏、面包屑与 `TabsView`，不再使用简化的手写侧栏。

- 给公共布局增加可选菜单、导航回调、标题及内容/面包屑/标签插槽；未传入时保留原来的独立应用行为。
- 组合菜单保留来源应用和层级，搜索使用当前组合应用菜单。
- 标签支持农业/IoT 跨源切换、关闭、关闭其他/左侧/右侧、刷新及内容最大化，跟随原有标签样式偏好。
- 标签只保存路由 key，按 tenantId + appKey 分开存入 sessionStorage；恢复时与当前授权页面取交集，移除失效/越权路径。
- 刷新重新加载当前授权深链接，保留标签；避免原地销毁无界实例时影响宿主路由。
- 同时处理无界首次挂载和缓存实例 activated，避免切回标签后加载遮罩不消失。
- 农业、IoT 的 HOST 模式不展示子应用自己的布局偏好按钮；SELF 模式不覆盖原偏好。
- 未改动数据库、套餐、角色和后端权限校验。

## 验证

- SaaS 微应用测试：5 文件、20 项全部通过。
- 农业/IoT 嵌入布局测试：各 2 项通过。
- SaaS typecheck、生产 build、git diff --check 通过。
- 浏览器确认完整工具栏、面包屑、可折叠菜单和标准标签外观。
- 实际打开人员管理、邀请码；标签切回成功，关闭邀请码返回人员管理；刷新后保留两个标签与当前页面。
- 组合应用中打开 IoT 产品，返回农业人员管理，再切回缓存的 IoT 标签。

验证范围为本次布局与导航；未执行业务数据写入，也未宣称所有布局偏好、所有业务页面或完整角色矩阵已验证。
